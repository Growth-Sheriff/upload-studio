## Submission wording boundary

Supported formulation: the service uses authenticated shop-scoped access, provider-encrypted current sensitive storage, verified TLS, private bearer-protected production files and implemented/tested privacy processing, with the precise retention/backup policies disclosed. Unsupported formulation: all disks/data have always been encrypted; all links expire within an hour; every privacy SLA/alarm/recovery flow is proven; no personal data is received; the system is HA/security-certified; or Shopify has already approved the protected-data answers.

The controller/processor, consent, sale/sharing and significant-decision applicability discussions in `pcd-groundtruth.md` are limited to this finished-sheet service. They are not generic N/A answers for an unseen future questionnaire. This handoff submits no checkbox and changes no runtime behavior.
